# Write a video script

1. Take the topic and the requested style guide. Use a guide explicitly selected earlier in the task when the request refers to it. If several guides fit and the choice materially changes the output, ask which one to use. Use the user's language, audience, platform, and duration preferences; for an unspecified Chinese medium-length video, aim for about five minutes.
2. Define the opening question or promise, build a sequence of beats with evidence and transitions, and plan a payoff that answers the opening. Apply the relevant long-video or short-form guidance. Use a fresh framing and original wording. Do not copy source sentences or present the draft as an actual work by the source channel.
3. Verify factual claims with relevant sources. Mark unresolved claims for checking, keep source notes outside the spoken text, and preserve the spoken flow.
4. Draft a title, opening, body, and ending. Read the script for spoken cadence, check the estimated duration and the continuity from opening to ending, then remove repeated points. Save the Markdown draft in the current workspace's designated output directory and return it in Codex. Only publish the draft elsewhere when requested.
